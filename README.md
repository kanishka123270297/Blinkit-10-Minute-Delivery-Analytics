# 💚 Blinkit: Inside the 10-Minute Delivery Model

## 📌 Project Overview
This is an independent Power BI case study inspired by Blinkit's quick-commerce delivery model. The project explores delivery performance, order trends, cancellations, and customer ratings using a public food-delivery dataset.

**Note:** This project is not affiliated with Blinkit and does not use official Blinkit data.

## 🎯 Business Objective
To explore how data analytics can help identify delivery inefficiencies, understand order patterns, and support better operational decision-making.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## 📊 Key Areas of Analysis
- Total Orders and Order Status Distribution
- Average Delivery Time
- On-Time Delivery Rate
- Estimated vs. Actual Delivery Time
- Order Trends Over Time
- Customer Ratings and Restaurant-wise Performance

## 💡 Key Learnings
- Data cleaning and transformation
- KPI creation using DAX
- Interactive dashboard development
- Business problem-solving through data analysis

## 📌 Dataset Disclaimer
The analysis uses a public food-delivery dataset. All findings relate to this dataset and should not be interpreted as Blinkit's actual business performance or internal operations.
